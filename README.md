One letter, one answer: **A** — coffee. The entry is a single character
in `entry.txt`, written by `main.py`.

Coffee is the louder ritual: steam off the mug, bold aroma, the clatter
of mugs, caffeine mornings. Against tea's calm, coffee is the vivid,
funny, true choice — the drink that announces itself before you taste it.

## Run

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output`), gated to
exactly one character and verified byte-for-byte.
